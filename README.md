## 一、Ubuntu VPS 到底是干嘛用的，谁该上这台车

Ubuntu 是目前 VPS 上最主流的 Linux 发行版之一，社区大、文档全、PPA 多，新手遇到问题搜一下基本都能找到答案。相比 Debian 的"能不更新就不更新"哲学，Ubuntu LTS 两年一更、五年支持的节奏更适合想用新特性又不想天天折腾的人。

它适合这几类场景：

- **个人开发者**：跑 Next.js、Django、Flask、Go API，或者做 CI/CD 的 runner
- **自托管玩家**：Nextcloud、Vaultwarden、Headscale、Gitea、 Jellyfin 一锅端
- **轻量生产**：小型电商、博客、落地页，配 Nginx + Certbot 走 HTTPS

不适合的场景也得说清楚：完全不懂 Linux 又不想学的、流量很低的小博客（共享主机更划算）、对 Windows 生态强依赖的（老老实实选 Windows VPS）。

## 二、挑 Ubuntu VPS 该盯住哪几个指标

我把市面上排名靠前的几篇 Ubuntu VPS 评测文章翻了一遍，共性指标就这几条：

| 维度 | 看什么 | 为什么重要 |
| --- | --- | --- |
| CPU 单核频率 | 3.5 GHz 以上算高频，5 GHz+ 算顶级 | 单核性能直接决定编译、PHP、Node 启动速度 |
| 虚拟化类型 | KVM 优于 OpenVZ/LXC | KVM 隔离好、能装 Docker、内核可换 |
| 存储 | NVMe > SSD > HDD | 数据库、容器启动速度差异巨大 |
| 月流量 | 注意是否"超量限速"还是"超量收费" | 限速型不会有意外账单 |
| 数据中心位置 | 选离用户近的，亚太用户优先 HK/JP | 延迟从 30ms 到 250ms 的差距，体验天差地别 |
| 备份策略 | 自动 + 异地 | 一旦误删 / 被入侵能回滚 |
| 隐藏费用 | IPv4 是否单独收费、超额带宽费 | 有些商家标价 2 美元，结账变 5 美元 |

这里面"单核频率"是被很多新手忽略的关键。多核看着唬人，但绝大多数 Web 工作负载是单线程为主，3.5 GHz 的一核能顶 2.4 GHz 的两核。

## 七、从零部署一台 Ubuntu VPS 的完整流程

Evoxt 官方有一份 10 步部署指南，我把它和 Ubuntu 实战结合起来重写一遍，去掉营销话术，留下真有用的部分。

**1. 进入部署页**

登录控制台后从 Dashboard 跳转，或直接访问部署页（文末 AFF 链接直达）。

**2. 选区域**

中国大陆/亚太用户优先香港（Premium）或大阪。北美用户选美国（Standard）。测试可以用 `ping.pe` 对比各节点延迟。

**3. 选规格**

参考上面的套餐表。不确定就 VM-1 起步，控制面板里随时能升级。

**4. 选操作系统**

这里就是 Ubuntu VPS 的核心动作。Evoxt 提供 Linux 模板（包含 Ubuntu LTS、Debian、AlmaLinux、Rocky Linux 等），选 Ubuntu 即可。后续还能在控制面板一键重装为别的发行版。

**5. 选数量**

同规格一次最多部署多台，省得一台台点。

**6. 填 hostname**

比如 `web-prod-01`，方便日后管理多机环境。

**7. 可选配置**

- **SSH Key**：强烈建议填，禁用密码登录是 Ubuntu 服务器安全的第一道闸
- **Startup Script**：可以塞一段 `apt update && apt install -y docker.io` 这种初始化脚本，开机自动跑
- **Disable IPv6**：除非你确定不用，否则别勾

**8. 选计费周期**

参考上面的省钱公式。新手建议月付，跑顺了再切年付。

**9. 选支付方式**

- 想留隐私：Bitcoin / USDT，无手续费，但到账慢 1 小时左右
- 想最快上线：信用卡 / PayPal，几分钟到账
- 中国用户：Alipay 也可，手续费通常比信用卡低

结账时记得手填推荐码再省 5%。

**10. 点 Deploy**

Linux 一般 2.5 分钟内、最长 5 分钟可 SSH 连入；Windows 和一键应用可能要 15 分钟。账号信息（IP + root 密码）会发到注册邮箱。

## 八、Ubuntu 装好后必做的 5 件事

部署完拿到 IP 不是终点，是起点。下面这五步不做好，再高频的 CPU 也救不了被扫描爆破的服务器。

bash
# 1. 更新系统
apt update && apt upgrade -y

# 2. 创建非 root 用户并加 sudo
adduser deploy
usermod -aG sudo deploy

# 3. 配置 SSH key 登录（在本地生成后上传）
ssh-copy-id deploy@your_server_ip

# 4. 禁用 root 密码登录
sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart ssh

# 5. 装防火墙
apt install -y ufw
ufw allow 22
ufw allow 80
ufw allow 443
ufw enable


做完这五步，再用 `fail2ban` 防爆破、装个 Docker 跑容器、配 Certbot 上 HTTPS，一台正经的 Ubuntu VPS 才算真的就位。
